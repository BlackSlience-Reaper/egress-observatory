安装与手动导入

服务器自动补充；插件使用当前 Chrome 会话读取 18 个来源。人机验证由你手动完成，通过后自动补充。

  1. 下载并解压插件。
  2. 打开 chrome://extensions，开启“开发者模式”。
  3. 加载解压后的 browser-helper 文件夹。更新时替换原文件夹并点“重新加载”。
  4. 刷新本页，点击“查询”。

临时标签自动分组、读完关闭；等待验证时保留，停止等待或切换查询时清理。Cookie 留在浏览器内。源码与权限 ↗

导入 IPinfo 网页

打开当前 IP 的 IPinfo 详情页 ↗，全选复制页面文字，粘贴后点击导入。

从 IPSuper 补全缺失类型

将「导入类型」拖到书签栏，再打开当前 IP 的 IPSuper 查询。结果完整后点击书签，会在新页面按数据库补全缺失字段。

导入类型 · 打开 IPSuper 查询 ↗
从来源网页补全

查询时会自动尝试来源网页。将「导入来源网页」拖到书签栏；在 IPHub、IPQualityScore、IPData、IPRegistry、DB-IP、Scamalytics、IP2Location、GreyNoise 或 ipapi.is 的目标结果页点击书签，可回传已显示的字段。只补充当前 IP 的缺失字段，同库合并。
